# Post patterns by intent

Not a single template. Pick the pattern that matches what the reader of the keyword is trying to do, then place the product evidence where it answers the next question the reader has. If the SERP shows a different intent, follow the SERP.

Every pattern ends the same way: a close in the "beat the store next to you" angle and an end CTA. Every pattern keeps the product under ~30% and passes the value test.

| Pattern | Use for | Tier |
|---|---|---|
| Diagnosis | "why is my …", "… not converting" | T1 |
| Plan by stages | "how to increase …", "how to improve …" | T1 |
| Checklist with pass/fail | "is my store ready for …", audits | T1 |
| Process | "how to find …", "how to redesign …" | T1/T2 |
| Comparison | "best … tools", "X vs Y", cost | T1/T2 |
| Anatomy | "what is …", "… examples", "… page" | T2/T3 |
| Numbers | "… statistics", benchmarks | T3 |

## Diagnosis (symptom → cause → check → fix)
- **Skeleton:** lede with the likeliest cause → three quick reports/checks to open first → N causes, each as symptom / how to check / fix → which to fix first (with the principle behind the order) → what if none fits.
- **Product block:** the verdict + ranked fixes of one real audit (what the audit flagged and the evidence on the page), or an aggregate ("the theme most audits flag", n ≥ 30).
- **Diagrams:** a decision tree of 3 questions; a map of the causes along the visit.

## Plan by stages (funnel order)
- **Skeleton:** lede → find the leakiest stage with the reader's own funnel report → fixes grouped by stage (first screen, product, cart, checkout) → impact/effort ordering → how to tell a change worked.
- **Product block:** the annotated screenshot of a real store with its #1 fix (Free shows fix #1), or the category scores that show where cold traffic leaks.
- **Diagrams:** the funnel with the main lever per stage; an impact/effort matrix (label it as judgment).

## Checklist with pass/fail
- **Skeleton:** lede with the verdict rule → each check as pass test / if it fails → mistakes that make a store look ready when it is not → how to read the score → next step.
- **Product block:** the ad-readiness verdict with its blockers on a real audit; the modeled ROAS range panel (everyone has it).
- **Diagrams:** scorecard; the click-to-purchase path with where each check breaks.

## Process (find / redesign / do X)
- **Skeleton:** lede with the process in one sentence → steps in order, each with what to record → how to apply without breaking anything (duplicate the theme, change one thing) → mistakes → when to stop.
- **Product block:** annotated screenshot + strengths and weaknesses; comparison with the same-niche leader (Library / competitor track, only anonymized).
- **Diagrams:** the process in 4–5 steps; a template the reader copies.

## Comparison (tools, cost, X vs Y)
- **Skeleton:** lede with the decision rule → a table by option with what each includes and where it stops (attribute every price and say who publishes it) → when each is worth it → red flags → where an automated audit fits.
- **Product block:** only the part of EliteVault that belongs in the comparison, with its limits ("it reads a screenshot, not your analytics").
- **Diagrams:** a ladder by price/depth; a ✓/— matrix of what each option delivers.

## Anatomy / definition
- **Skeleton:** lede with the definition → the parts and what each does → examples with the reason each works → common mistakes → how to check yours.
- **Product block:** the annotated screenshot of the part being explained.
- **Diagrams:** an annotated wireframe; before/after of one element (illustrative, labeled).

## Numbers (statistics)
- **Skeleton:** lede with the headline figure and its source → figures grouped by use, each re-verified at its primary source → how to use them without over-reading → our own aggregate data (n ≥ 30) as a clearly separated section.
- **Product block:** `docs/blog-data/a2-aggregates.json` figures with their sample line.
- **Diagrams:** bar chart per group with the source in the caption.

## Where the funnel steps go (all patterns)
1. **Problem** in the first screen (lede + video bridge).
2. **Self-diagnosis** the reader can run alone (steps, checklist, diagram). Early CTA before the first third.
3. **Where it gets hard by hand** (compare with the niche leader; model before spending).
4. **EliteVault in action**, then the showcase CTA.
5. **Honest next step:** what unlocks next and why it helps this reader.
6. Close in the "unbeatable" angle, end CTA.
